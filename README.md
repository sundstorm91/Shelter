# 🐾 Shelter — адаптивный сайт приюта для животных

Двухстраничный сайт (главная + страница питомцев) с каруселью, пагинацией, модальными окнами и бургер-меню. Первый опыт реализации сложного UI на чистом JS.

## 🛠️ Tech Stack

- **HTML5 / CSS3** — семантическая вёрстка, Flexbox, Grid, медиазапросы
- **Vanilla JS** — вся интерактивная логика (карусель, пагинация, модалки, бургер)
- **БЭМ** — наименование классов

## 🧩 Функционал

| Страница              | Элементы                                                                                     |
| --------------------- | -------------------------------------------------------------------------------------------- |
| **Главная**           | Бургер-меню, слайдер с карточками питомцев, модалки с детальной информацией                  |
| **Страница питомцев** | Пагинация (8 карточек на страницу), кнопки перехода (вперёд/назад/в начало/в конец), модалки |
| **Общее**             | Адаптив под 3 брейкпоинта, плавный скролл по якорям                                          |

## 🧠 Что дал этот проект

- Реализация **бесконечной карусели** на чистом JS (клонирование карточек, расчёт ширины)
- Реализация **пагинации** с нуля (без библиотек)
- Работа с **модальными окнами** (открытие/закрытие по клику)
- Опыт адаптивной вёрстки сложных секций
- Понимание **DOM-манипуляций** и управления классами
